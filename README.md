## Что это

Загружаете `.mov` с кассовой камеры (верхний ракурс, без звука, 10–145 с) → сервис ищет признаки
нарушений кассовой дисциплины → возвращает:

- **вердикт** — «Нарушение не обнаружено» / «Обнаружены признаки возможных нарушений»;
- **тип** каждого нарушения (списком — в одном видео их может быть несколько);
- **точный таймкод** события;
- **1–3 кадра-доказательства** (JPEG, base64);
- **обоснование** с ссылкой на точный пункт НПА Республики Казахстан.

Всё работает полностью локально: после загрузки весов сервису интернет не нужен.

```
.mov ──▶ детекция (1 fps) ──▶ таблица фактов ──▶ движок правил ──▶ вердикт
        RF-DETR nano ×7 классов   0.5 с тики,       11 правил (order + streak)
        RF-DETRBase (person)      трекинг, зоны     + merge → список
```

## API (раздел 10 ТЗ)

Заголовок авторизации — `X-API-Key`.

```bash
# загрузить видео на анализ
curl -X POST <URL>/api/v1/analyze -H "X-API-Key: <ключ>" -F "file=@video_017.mov"
# → {"job_id": "..."}

# опросить задачу
curl <URL>/api/v1/jobs/<job_id> -H "X-API-Key: <ключ>"
# → {"status": "processing"} →
# {"status": "done", "verdict": "violation", "violations": [{"type", "timecode_sec",
#   "description", "evidence_frames": [{"timestamp_sec", "image_base64"}]}]}
```

### Правила движка

| ID | Тип | Суть | НПА |
|----|-----|------|-----|
| R1 | Приём денег без проверки документа | документ не проверен до приёма наличных | № 231, п. 19 пп. 1 |
| R2 | Безнадзорные ценности | купюры/мешок на столе при отошедшем кассире | № 231, п. 20 абз. 2 |
| R3 | Сейф/ключ без присмотра | открытый сейф или ключ в замке при уходе | № 231, п. 20/76; № 14, п. 16 пп. 1 |
| R4 | Деньги клиента не выданы | сеанс завершён, пачка осталась на столе | признак |
| R5 | Два клиента одновременно | второй клиент в кассовой зоне во время обслуживания | признак |
| R6 | Пересчёт без клиента | пересчёт в отсутствие клиента | № 231, п. 20 абз. 1 |
| R7 | Личные вещи в кассовом узле | одежда/сумка на кассовом столе | № 231, п. 12 |
| R8 | Порядок рабочего места | штампы/экран открыты при уходе кассира | признак |
| R9 | Кассовая зона не закрыта | дверь открыта, посторонние при открытой двери | № 231, п. 22 |
| R10 | Приём без пересчёта и оформления | деньги ушли в сейф без пересчёта/оформления | № 231, п. 19 |
| R11 | Деньги не убраны при приёме следующего клиента | старые деньги при новом клиенте → смешивание | № 231, п. 20 абз. 2 |

Нормативная база — только акты РК: Постановления Правления НБ РК № 231 (29.11.2019, V1900019680)
и № 14 (24.02.2020, V2000020075). Цитаты с привязкой к правилам и сверка по adilet.zan.kz — в
[`law.md`](./law.md).

## Дизайн: почему так

- **Нейросеть видит только нейтральные примитивы** (купюры, документ, сейф, штамп, люди) —
  не «нарушения». Модель не переобучается на редких тренировочных примерах и не «выносит приговор».
- **Вердикт выносит детерминированный движок**: правила заданы как данные с порогами
  (`pipeline/rules.py`, `Config`), решение воспроизводимо и разматывается до
  «кадр → факт → условие → пункт НПА».
- **Словарь дополняемый**: новый класс = дообучение детектора; правило по нему добавляется
  строкой в данные, дерево не переписывается. Совпадения вне известных правил отдаются честным
  «признаком, требует проверки» (ответ на FAQ про неизвестные типы).
- Лица не распознаются и не хранятся; звук отсутствует в принципе.

Детектор — Apache-2.0 стек (RF-DETR / supervision), пригодный под коммерческое использование.

## Запуск

```sh
# backend (API + worker + статика UI)
cd backend && pip install -r requirements.txt && uvicorn main:app

# frontend — отдельно в dev-режиме
cd frontend && npm ci && npm run dev
```

Скрипт сборки и запуска на сервере — [`DEPLOY.md`](./DEPLOY.md), санити-проверка движка:

```sh
python3 scripts/run_sanity.py   # 6 фикстур рукописных таблиц фактов
```

## Карта репозитория

| Путь | Что это |
|------|---------|
| `pipeline/` | движок: `facts.py` (таблица фактов), `rules.py` (правила+пороги), `engine.py` (вердикт) |
| `backend/` | FastAPI: `/analyze`, `/jobs`, `X-API-Key`, воркер обработки |
| `frontend/` | Forte Vision — React UI (демо-режим без ключа, живой анализ с ключом) |
| `scripts/` | детекция, трекинг, факты, сверки (`eval_labels.py`, `run_sanity.py`) |
| `fixtures/` | рукописные таблицы фактов для калибровки движка |
| `law.md` | нормативка РК: цитаты → правила |
| `rules_tree.html` | интерактивный драфт словаря примитивов и дерева решений |
| `labels.csv` | официальные метки организаторов (Х-4 = Х-47, Х-5 = Х-48 — дубликаты) |
| `review.html` | редактор командной разметки (инструкция — `annotations_README.md`) |
| `strips/`, `sheets/` | ленты 1 к/с для быстрого просмотра роликов без плеера |
