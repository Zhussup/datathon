# Forte Vision

Frontend сервиса проверки кассовых операций по видео для кейса ForteBank Datathon 2026.

## Запуск

Требуется Node.js 22.12+ и npm.

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

```sh
npm test         # проверка файлов и таймкодов
npm run build    # TypeScript и production-сборка
npm run preview  # локальный просмотр production-сборки
```

## Возможности прототипа

- Выбор или перетаскивание одного MOV/MP4 до 200 МБ; проверка расширения, пустого файла и размера.
- Локальный видеоплеер: пауза, перемотка, полноэкранный просмотр. Поддержка MOV зависит от кодека браузера; для предпросмотра рекомендуется MP4/H.264.
- Имитация этапов обработки выбранного файла с прогрессом и возможностью сброса.
- Два демонстрационных результата: с возможными нарушениями и без событий.
- Карточки событий с таймкодами, иллюстрацией, наблюдением и объяснением.
- Адаптивный интерфейс на русском, клавиатурное управление вкладками, поддержка reduced motion.

## Границы реализации

Только frontend. AI-модель, backend, API и нормативные источники пока не подключены. Загруженные файлы не анализируются, им не присваивается вердикт. Демонстрационные события заданы в `src/demo.ts`, а изображение кассовой зоны — SVG-иллюстрация, не реальная запись и не кадр-доказательство. Правовые ссылки и пункты регламентов не выдуманы: в интерфейсе показано, что источник ещё не подключён.

Видео открывается через `URL.createObjectURL`, не передаётся на сервер и не сохраняется между перезагрузками. Неиспользуемые object URL и таймеры освобождаются. Шрифты и графика не требуют внешних сервисов.

## Структура

- `src/App.tsx` — экран проверки, демосценарии, загрузка и плеер.
- `src/DemoScene.tsx` — иллюстрация кассовой зоны.
- `src/Icon.tsx` — SVG-иконки интерфейса.
- `src/demo.ts` — демоданные, валидация и форматирование времени.
- `src/style.css` — оформление и адаптивная сетка.

Для подключения backend замените демообработку отправкой `FormData` с полем `file` на `POST /api/v1/analyze` и опросом `GET /api/v1/jobs/{job_id}`. Ключи доступа не следует встраивать в исходники или frontend-сборку. Фактические вердикты, события, кадры и проверенные нормативные ссылки должен возвращать сервер.
